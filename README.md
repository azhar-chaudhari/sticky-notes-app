# Stickies · Modern Sticky Notes App

A sleek, browser‑based sticky notes application with persistent storage, real‑time search, color customization, and export capabilities. Built with vanilla HTML/CSS/JS and IndexedDB.

![Screenshot](https://via.placeholder.com/800x450?text=Stickies+Demo)

## ✨ Features

- **Create & Edit Notes** – Add unlimited sticky notes with auto‑saving content.
- **Persistent Storage** – All notes are saved locally using IndexedDB (no backend required).
- **Rich Color Palette** – Choose from 5 soft, modern colors per note (Yellow, Pink, Blue, Green, Purple).
- **Live Search** – Filter notes instantly by content as you type.
- **Relative Timestamps** – See when each note was last updated ("2 min ago", "yesterday", etc.).
- **Drag & Drop Ready** – Notes are draggable for flexible arrangement.
- **Export / Backup** – Download all notes as a JSON file.
- **Clear All** – One‑click deletion with confirmation dialog.
- **Responsive Design** – Works perfectly on desktop, tablet, and mobile devices.
- **No External Dependencies** – Pure vanilla implementation, lightweight and fast.
